# Ручной чек-лист приёмки

Поведение UI и платформенного слоя, которое не покрывается `swift test`. Проходить перед релизом.

- [ ] Диктовка в Terminal, в IDE (Xcode или VS Code) и в поле ввода в браузере вставляется корректно.
- [ ] Вставка работает при активной русской раскладке.
- [ ] Удержание и короткое нажатие работают; Esc отменяет запись, в историю ничего не попадает.
- [ ] Wi-Fi выключен → уведомление об ошибке, запись в истории с пометкой «ошибка»; после включения сети «Распознать заново» срабатывает.
- [ ] Accessibility отключён → уведомление «нажмите ⌘V», текст в буфере обмена.
- [ ] Профиль, изменённый в VS Code, применяется к следующей диктовке без перезапуска.
- [ ] Битый профиль виден в меню с ошибкой; если он был активным, используется «Без обработки».
- [ ] Две диктовки подряд, вторая начата во время обработки первой: обе вставлены, буфер обмена восстановлен.
- [ ] Индикатор вверху экрана: запись с уровнем и таймером → «Распознаю…» → «Обрабатываю…» → «Вставлено», затем исчезает; фокус не уходит из активного окна.
- [ ] Выбор микрофона в настройках: со встроенным микрофоном и Bluetooth-наушниками звук начала записи слышен, музыка не прерывается.
- [ ] Иконка: красная во время записи, анимированная во время обработки (если анимация в строке меню не работает, иконка просто остаётся волной — это допустимо).
- [ ] Диктовка дольше 10 минут останавливается автоматически и обрабатывается.
- [ ] «Расход за месяц» в истории растёт после диктовок.
- [ ] Первый запуск новой версии: в «iCloud Drive → Quill» появились `settings.json` с текущими моделями и прежние профили.
- [ ] «Показать» и «Скопировать» ключа работают; ссылка «Создать ключ на OpenRouter» открывается.
- [ ] Модель, изменённая в настройках, записывается по Enter или при уходе из поля, а не на каждую букву.
- [ ] Второй ноутбук после установки получает те же профили и модели; изменение на одном видно на другом без перезапуска.
- [ ] Модель вставлена в поле и окно настроек сразу закрыто крестиком: после повторного открытия значение сохранилось.
- [ ] Недописанная модель не пропадает после переключения в браузер и обратно.
- [ ] Битый `settings.json` (например, удалить закрывающую скобку): приложение работает, в настройках красное предупреждение.
- [ ] Микрофон отдаёт тишину (например, выбран микрофон iPhone через Continuity при заблокированном телефоне): после остановки — уведомление «Микрофон «…» не передал звук», запись в истории с ошибкой, аудио сохранено, в OpenRouter ничего не отправлено.
- [ ] `/usr/bin/log show --last 10m --info --predicate 'subsystem == "dev.saldin.quill"'` показывает start/capture/stop/finished для каждой диктовки: устройство, длительности, размер файла; текста диктовки в логе нет.
- [ ] Микрофон iPhone (Continuity): короткое нажатие запускает запись, она идёт до второго нажатия, хотя подключение занимает несколько секунд.
