# OpenWhisper

Личное приложение для диктовки на macOS в строке меню: горячая клавиша → речь →
распознавание и постобработка через OpenRouter → вставка в активное окно.

## Сборка

Нужны Xcode 27 (лицензия принята), XcodeGen (`brew install xcodegen`) и вход в Xcode
с Apple ID (Personal Team, подпись Apple Development).

```bash
make test     # тесты логики
make install  # сборка, копия в ~/Applications и запуск
```

## Перенос на другой Mac

```bash
make release   # оптимизированная сборка → build/OpenWhisper.zip
```

На другом Mac:

1. Перед первым запуском откройте в Finder «iCloud Drive → OpenWhisper» и дождитесь `settings.json` и `profiles/`.
2. Распакуйте `OpenWhisper.zip` в `~/Applications` (или `/Applications`).
3. Сборка не нотаризована, поэтому macOS её заблокирует. Один раз выполните
   `xattr -dr com.apple.quarantine ~/Applications/OpenWhisper.app`
   или откройте приложение и нажмите «Всё равно открыть» в «Системные настройки → Конфиденциальность и безопасность».
4. Дальше — как «Первый запуск» ниже: ключ OpenRouter, доступ к микрофону и Accessibility, микрофон и горячие клавиши.

## Первый запуск

1. Меню → «Настройки…» → вставить ключ OpenRouter → «Проверить».
2. Разрешить микрофон (спросит при первой записи) и Accessibility (кнопка «Запросить»).
3. Иконка-волна в строке меню; если её не видно (строка переполнена или скрыта «чёлкой»),
   повторно откройте OpenWhisper из «Программ» или Spotlight — откроются настройки.
4. ⌥Space — запись (удержание — «держи и говори», короткое нажатие — старт/стоп), Esc — отмена.
   ⌥⇧P — следующий профиль. Клавиши меняются в настройках.

## Профили

Файлы `iCloud Drive/OpenWhisper/profiles/*.md` (без iCloud Drive — `~/.config/openwhisper/profiles/`).
Имя файла — id профиля. Профили и `settings.json` в той же папке общие для всех ваших Mac.

**Второй Mac:** перед первым запуском откройте в Finder «iCloud Drive → OpenWhisper» и дождитесь,
пока там появятся `settings.json` и `profiles/`. Иначе приложение создаст свои встроенные профили,
и iCloud сделает конфликтные копии (`clean 2.md`, `settings 2.json`) — их можно просто удалить.

```markdown
---
name: Frontend / Claude Code
transcription_model: openai/gpt-4o-transcribe   # необязательно
llm_model: openai/gpt-4.1-mini                  # необязательно
postprocess: true                               # false — вставлять сырой текст
language: ru                                    # необязательно
vocabulary:
  - useState
  - frontend-config
---
Инструкция для постобработки в этом проекте.
```

Словарь применяется только на этапе постобработки: эндпоинт распознавания OpenRouter
подсказки не принимает.

## Данные

- Общие настройки: `iCloud Drive/OpenWhisper/settings.json` (модели, лимит аудио, звуки, индикатор)
- История: `~/Library/Application Support/OpenWhisper/history.sqlite`
- Аудио: `~/Library/Application Support/OpenWhisper/audio/` (ротация по лимиту из настроек, по умолчанию 1 ГБ)
- Ключ: Keychain этой машины, service `dev.saldin.openwhisper` (не синхронизируется: «Настройки… → Показать/Скопировать»)

## Ручной чек-лист приёмки

- [ ] Диктовка в Terminal, в IDE (Xcode или VS Code) и в поле ввода в браузере вставляется корректно.
- [ ] Вставка работает при активной русской раскладке.
- [ ] Удержание и короткое нажатие работают; Esc отменяет запись, в историю ничего не попадает.
- [ ] Wi-Fi выключен → уведомление об ошибке, запись в истории с пометкой «ошибка»; после включения сети «Распознать заново» срабатывает.
- [ ] Accessibility отключён → уведомление «нажмите ⌘V», текст в буфере обмена.
- [ ] Профиль, изменённый в VS Code, применяется к следующей диктовке без перезапуска.
- [ ] Битый профиль виден в меню с ошибкой; если он был активным, используется «Без обработки».
- [ ] Две диктовки подряд, вторая начата во время обработки первой: обе вставлены, буфер обмена восстановлен.
- [ ] Индикатор вверху экрана: запись с уровнем и таймером → «Распознаю…» → «Обрабатываю…» → «Вставлено», затем исчезает; фокус не уходит из активного окна.
- [ ] Выбор микрофона в настройках: со встроенным микрофоном и Bluetooth-наушниками звук начала записи слышен, музыка не прерывается.
- [ ] Иконка: красная во время записи, анимированная во время обработки (если анимация в строке меню не работает, иконка просто остаётся волной — это допустимо).
- [ ] Диктовка дольше 10 минут останавливается автоматически и обрабатывается.
- [ ] «Расход за месяц» в истории растёт после диктовок.
- [ ] Первый запуск новой версии: в «iCloud Drive → OpenWhisper» появились `settings.json` с текущими моделями и прежние профили.
- [ ] «Показать» и «Скопировать» ключа работают; ссылка «Создать ключ на OpenRouter» открывается.
- [ ] Модель, изменённая в настройках, записывается по Enter или при уходе из поля, а не на каждую букву.
- [ ] Второй ноутбук после установки получает те же профили и модели; изменение на одном видно на другом без перезапуска.
- [ ] Модель вставлена в поле и окно настроек сразу закрыто крестиком: после повторного открытия значение сохранилось.
- [ ] Недописанная модель не пропадает после переключения в браузер и обратно.
- [ ] Битый `settings.json` (например, удалить закрывающую скобку): приложение работает, в настройках красное предупреждение.
